# CIFAR-10 experiment

This Axon model classifies the ten object categories in CIFAR-10. The maintained training code is in [`cifar10.ex`](cifar10.ex); setup and execution commands are in the [repository README](../../../../README.md).

The original capstone repository marked the CIFAR-10 experiment as unfinished and did not include a result figure here. The updated model passes synthetic inference, training, and evaluation checks. A full dataset run should be recorded before publishing a new CIFAR-10 result.
